# Glossary: episode 9

- **Configuration rule**: A rule that keeps a product's choices valid: a condition and an action.
- **Rule scope**: Where the rule applies, for example the product being configured.
- **Condition**: The "if" part of a rule, for example Body equals Refrigerated.
- **Action**: The "then" part, for example set an attribute or disable one of its values.
- **Rule sequence**: The order in which rules run, lowest number first.
- **Business Rules Engine (BRE)**: The Salesforce engine that runs these rules.
- **Constraint Rules Engine and CML (Constraint Model Language)**: A second engine that uses a modelling language. Named here, not used.
- **Product recommendations**: Suggestions of other products during configuration. Named here, not built.
- **Transaction Processing Type and the quote's Transaction Type**: The setting that tells a quote which rules engine to use.
