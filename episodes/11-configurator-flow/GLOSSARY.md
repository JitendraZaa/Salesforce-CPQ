# Glossary: episode 11, The configurator flow

Terms introduced in this episode. The full project glossary is `GLOSSARY.md` in the repository root.

- **Product Configurator flow**: The screen flow that Salesforce shows when a user configures a product on a quote. It can be copied and changed.
- **Flow screen component**: A building block placed on a flow screen, for example Product Attributes or Summary.
- **Attribute sequence**: A whole number that sets the order in which attributes appear on the configurator screen.
- **Product configuration flow assignment**: The record that tells a product which configurator flow to use. A product has only one.
- **Retrieve**: Copying a setting from the org into files in the project, so it can be stored and deployed again.
