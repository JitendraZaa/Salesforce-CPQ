# Glossary: episode 15, Pricing from code

Terms introduced in this episode. The full project glossary is `GLOSSARY.md` in the repository root.

- **API**: A defined way for one program to ask another program to do something.
- **REST**: A common style of web API where each request goes to an address and uses a verb such as GET or POST.
- **HTTP and the POST verb**: HTTP is the language of web requests. POST sends data to be processed.
- **JSON**: A plain-text format for data made of names and values, in curly braces and lists.
- **OAuth**: The standard way a program is given permission to call an API without handing over a password.
- **Pricing API**: The service that prices items without a quote record, also called headless pricing.
- **Request body**: The data sent with a POST request.
- **Context mapping**: The link between nodes of the context definition and Salesforce objects such as Quote and QuoteLineItem.
- **Hydrate a context**: Fill the context definition with the data it needs before pricing runs.
