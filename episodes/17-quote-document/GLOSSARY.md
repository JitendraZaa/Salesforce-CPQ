# Glossary: episode 17, The quote document

Terms introduced in this episode. The full project glossary is `GLOSSARY.md` in the repository root.

- **Document generation**: Producing a document, here a PDF, from record data and a template.
- **Quote template**: The layout and wording of the document made from a quote.
- **Document Builder**: The Salesforce tool that creates quote templates and generates the PDF.
- **Template Builder**: The screen inside Document Builder where components are arranged.
- **Standard component**: A ready-made block in Template Builder, such as Quote Line Items or Image.
- **Default template**: The one active template used when a user generates a quote document. Only one can be the default.
