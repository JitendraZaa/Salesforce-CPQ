# Glossary: episode 23, Quote to order

Terms this episode introduces. The full project glossary is `GLOSSARY.md` in the repository root.

- **Final offer**: The last version of the quote the customer accepts.
- **O2C (order to cash)**: From the customer's order: fulfil, invoice, collect.
- **PO (purchase order)**: The buyer's own approval document, often needed before an invoice is paid. Here it is stored on the order.
- **Order**: The confirmed purchase.
- **Order product**: One product line on an order.
- **Order status**: Draft orders can change; an activated order cannot be edited.
- **PST (Place Sales Transaction)**: The API that creates or updates a quote or order with pricing and configuration in one call.
